## GL Code Approach

GL codes are determined by **what is being purchased**, not by vendor.
Always read the handwritten GL code on the invoice first — that is the authoritative source.
Only a small number of vendors (utilities, fixed recurring) have reliable default GL codes.
If the handwriting is illegible or absent, flag as REVIEW NEEDED and note the vendor/description
so the accounting team can assign the correct code from the chart of accounts.
